# RAGX Abbreviations

This glossary defines abbreviations used across the RAGX documentation. When an
abbreviation appears in a document, the first occurrence should use the format
`Full Name (ABBR)` unless the term is already defined in the local abbreviation
table.

| Abbreviation | Full Name | Chinese Note |
| --- | --- | --- |
| ACL | Access Control List | 访问控制列表，用于权限过滤。 |
| API | Application Programming Interface | 应用程序编程接口。 |
| BM25 | Best Matching 25 | 经典词法相关性排序函数。 |
| CJK | Chinese, Japanese, and Korean | 中日韩字符集合。 |
| CLI | Command-Line Interface | 命令行接口。 |
| ColBERT | Contextualized Late Interaction over BERT | 基于 token-level MaxSim 的 late-interaction 检索/重排方法。 |
| DOCX | Office Open XML Wordprocessing Document | Microsoft Word 文档格式。 |
| HNSW | Hierarchical Navigable Small World | 常见近似最近邻向量索引结构。 |
| JSON | JavaScript Object Notation | 结构化数据交换格式。 |
| JSONL | JSON Lines | 每行一个 JSON 对象的数据集格式。 |
| LLM | Large Language Model | 大语言模型。 |
| MRR | Mean Reciprocal Rank | 平均倒数排名。 |
| NDCG | Normalized Discounted Cumulative Gain | 归一化折损累计增益。 |
| OCR | Optical Character Recognition | 光学字符识别。 |
| PDF | Portable Document Format | 便携式文档格式。 |
| RAG | Retrieval-Augmented Generation | 检索增强生成。 |
| RRF | Reciprocal Rank Fusion | 倒数排名融合。 |
| SDK | Software Development Kit | 软件开发工具包。 |
| SHM | Shared Memory | SQLite 共享内存辅助文件。 |
| SQL | Structured Query Language | 结构化查询语言。 |
| WAL | Write-Ahead Logging | SQLite 预写日志文件。 |
